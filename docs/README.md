# 设计文档索引

本目录保存 `quadruped_control` 的长期架构、阶段方案、嵌入式指导和架构图。
仓库根目录的 `README.md` 说明当前已经实现的功能；本索引用于区分长期设计、待实施方案和
历史阶段记录。

## 推荐阅读顺序

1. [`quadruped_control_architecture.md`](quadruped_control_architecture.md)：长期模块边界、
   数据语义、部署方式和安全原则；
2. [`第一阶段仿真闭环开发说明.md`](第一阶段仿真闭环开发说明.md)：M0～M5 的仿真闭环路线；
3. [`M2_基础运动闭环开发方案.md`](M2_基础运动闭环开发方案.md)：已经完成的 M2 实施记录，
   包含配置、行为、任务拆分和人工验收要求；
4. [`M1_MuJoCo开环开发方案.md`](M1_MuJoCo开环开发方案.md)：已经完成的 M1 实施记录；
5. [`STM32H7 四足机器人下位机嵌入式开发指导.md`](STM32H7%20四足机器人下位机嵌入式开发指导.md)：
   后续 H7 路线的职责、安全和嵌入式约束。

## 参考项目

参考项目只提供已有行为、参数、模型和硬件事实。本仓库已经确认的文档、公共接口和依赖边界
具有更高优先级；出现冲突时不能直接照搬参考项目。

### `../rl_sar`

- 本次规划检查基线：提交 `4abccaa`；
- 许可证：Apache License 2.0；
- 主要参考内容：black/blackW 的状态行为、起立和趴下参数、策略配置、观测顺序、动作换算、
  手柄和 ROS 2 输入行为；
- 不直接迁移内容：线程模型、ROS 回调、动态容器式高频帧、旧 FSM 工厂和把输入设备按键直接
  写入运动状态机的方式；
- 如后续移植受版权保护的具体实现，必须保留适用的版权和许可证声明。

### `../real_robot`

- 本次规划检查基线：提交 `4662151`；
- 仓库根目录未发现许可证文件，因此只作为行为和硬件事实参考，不直接复制源码；
- 主要参考内容：MuJoCo 启动后执行器失能并自然落地的现有行为，以及实机电机映射、减速比、
  零点、IMU、串口和安全处置现状；
- M2 中只参考其 MuJoCo 初始落地行为，实机代码不进入当前实现范围。

### `../URDF`

black 的 M1 固定 MuJoCo 资产来自提交
`22c120bad450a81af2c4d6fcbf221262e2884928`。具体文件和导入范围见 M1 方案。
